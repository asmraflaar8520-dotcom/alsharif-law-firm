# الشريف وشركاه — نظام إدارة مكتب المحاماة
### Al-Sharif & Partners — Law Firm Management Platform

منصة رقمية متكاملة مصممة خصيصاً لإدارة أعمال مكاتب المحاماة والاستشارات القانونية وفق المعايير القضائية المصرية (قضايا، جلسات محاكم، موكلون، توكيلات، أتعاب وفواتير، ساعات عمل، مهام الفريق، والأرشيف الإلكتروني) بواجهة عربية متطورة وسريعة الاستجابة للهواتف المحمولة.

---

## 🏛️ نظرة عامة على النظام (Architecture Overview)

النظام مبني وفق معمارية حديثة ومجزأة (Modular Architecture) تضمن وضوح المسؤوليات وسهولة الصيانة والتوسع السريع:
- **إطار العمل (Backend):** [Hono](https://hono.dev) + TypeScript مخصص لبيئة Cloudflare Pages / Workers.
- **قاعدة البيانات (Database):** Cloudflare D1 (SQLite) مع أنظمة ترحيل (Migrations) وتلقيم بيانات واقعية (Seed).
- **الواجهة الأمامية (Frontend):** Vanilla JavaScript + TailwindCSS مع خطوط (Cairo & Amiri) وتصميم RTL متكامل ومحسن للهواتف الذكية.
- **الأمان والتحكم:** بروتوكول جلسات آمن عبر كوكيز `HttpOnly`، ونظام حماية ضد هجمات التخمين (Rate Limiting)، وترويسات أمان HTTP صارمة، وحماية من تصعيد الصلاحيات (RBAC).

## 🚀 التثبيت والتشغيل المحلي (Setup & Local Running)

### 1. المتطلبات:
- Node.js (الإصدار 18 فما فوق).
- npm أو pnpm.

### 2. تثبيت الحزم:
```bash
npm install
```

### 3. بناء المشروع وتحديث قاعدة البيانات:
```bash
npm run build
npm run db:migrate:local
npm run db:seed
```

### 4. تشغيل خادم التطوير المحلي:
```bash
npm run preview
```
التطبيق سيعمل فوراً على الرابط:
**http://localhost:3000** أو **http://127.0.0.1:3000**

## 🛡️ ميزات الأمان والأداء المدمجة
1. **Rate Limiting:** حد أقصى 10 محاولات دخول فاشلة كل 15 دقيقة لمنع هجمات التخمين.
2. **Security Headers:** إرسال تلقائي لترويسات `SAMEORIGIN`, `nosniff`, و `strict-origin-when-cross-origin`.
3. **Safe Database Updates:** استخدام تحديثات آمنة تمنع الكتابة العشوائية أو حذف الحقول القديمة عند التعديل الجزئي.
4. **Mobile Responsiveness:** متوافق تماماً مع الهواتف الذكية مع شريط تنقل سفلي سريع ودرج جانبي متجاوب ومنع زوم الشاشة التلقائي.
5. **Zero-Lag Navigation:** كاش محلي للواجهة الأمامية لتفاصيل القضايا يمنع إعادة سحب البيانات غير الضرورية عبر الشبكة.

## 🧩 كيفية إضافة ميزة جديدة (Extending the Codebase)
لإضافة ميزة جديدة (مثال: إدارة الاستشارات القانونية `consultations`):
1. **قاعدة البيانات:** أضف ملف ترحيل جديد في `migrations/` وأنشئ جدول `consultations`.
2. **الأنواع:** عرّف واجهة `Consultation` في `src/types.ts`.
3. **المسارات:** أنشئ ملف مسار جديد `src/routes/consultations.ts` مع استعلامات الـ SQL والتحقق من الصلاحيات.
4. **الربط:** قم بربط المسار في `src/index.tsx` عبر `app.route('/api/consultations', consultationRoutes)`.
5. **الاختبارات:** أضف حالات اختبار تكاملية في `test/api.test.mjs`.
